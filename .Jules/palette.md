## 2024-05-24 - Progress Bar Accessibility\n**Learning:** Custom visual progress bars (e.g. using framer-motion) lack screen reader semantics by default, which hides important quantitative data like threat scores from assistive technologies.\n**Action:** Always add `role="progressbar"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, and a localized `aria-label` (e.g. "Уровень опасности") to the container element of custom progress bars.
