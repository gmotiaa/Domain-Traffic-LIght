## 2024-04-28 - Focus States in SiteHeader
**Learning:** In heavily stylized floating headers with glassmorphism backgrounds (`bg-white/5` or `bg-background/40`), the standard focus ring color (often a bright blue or standard theme color) clashes and can be hard to see. Using a semi-transparent white ring (`focus-visible:ring-white/50`) blends perfectly with the existing "liquid-glass" design language while remaining distinct enough for accessibility visibility.
**Action:** Always test keyboard navigation on custom transparent components and apply `focus-visible:ring-white/50` or similar opacity-matched rings rather than relying on default focus styles.
